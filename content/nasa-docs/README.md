# NASA source documents

Put the source documents for the assistant here as `.md` or `.txt` files, one
topic per file, with the source link on the first line.

The assistant retrieves passages from these files and cites the file name. With
no documents here it says so and answers nothing medical.

Suggested starting points: the NASA Human Research Program pages on the five
hazards of human spaceflight, and the HRP risk summaries.
