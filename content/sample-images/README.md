# Sample images

Drop a handful of real example photos here (skin/rash/wound, the kind an
astronaut might send through the Assistant page) as `.jpg`/`.jpeg`/`.png`
files. `GET /sample-images` on the Assistant service lists whatever is in
this folder, and the frontend's "try a sample" picker uses that list --
useful for a demo when nobody has a real photo handy.

Empty by default: nothing invented or placeholder-generated here, since a
fabricated medical photo would be worse than no demo picker at all.
